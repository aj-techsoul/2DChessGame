# ♞ Chess AI Master

A 2D Chess game with AI opponent powered by Minimax + Alpha-Beta Pruning.

---

## 🚀 Getting Started

**Requirements:** Node.js 18+

```bash
# 1. Clone the repo
git clone https://github.com/aj-techsoul/2DChessGame.git
cd 2DChessGame

# 2. Install dependencies
npm install

# 3. Start the game
npm run dev
```

Then open **http://localhost:5173** in your browser. 🎉
